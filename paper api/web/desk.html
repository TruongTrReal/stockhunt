TradingView webhook

TradingView can only post a JSON body — it cannot send your API key in a header. So this strategy gets its own secret, and that secret can do exactly one thing: place orders for this strategy. It is not your API key and must never be replaced with one.

Refused

The desk read these and would not run them. Nothing was traded and nothing is recorded, so removing one loses nothing. Desk says carries the reason — most are fixable by registering again with a different timeframe, symbol or asset class.

Retired

Stopped, and kept. Fills, equity curve and gaps stay in the desk's record forever — a forward test you can erase is not a record. One that never placed an order recorded nothing, so that one can be removed.
